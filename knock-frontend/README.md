# Knock Frontend

Knock Market 프론트엔드 애플리케이션입니다.  
Vite + React + TypeScript 기반으로 동작하며 `/api/v1` 백엔드 API를 사용합니다.

## Prerequisites

- Node.js 22+

## Run

1. 의존성 설치
   - `npm install`
2. 개발 서버 실행
   - `npm run dev`
3. 프로덕션 빌드
   - `npm run build`

## Quality Gate

- 타입 체크: `npm run typecheck`
- 린트(타입 기반): `npm run lint`
- 테스트(현재 타입 기반): `npm run test`
