# Knock Market 구현 상태 가이드 (v1.4)

## 1. 서비스 개요

Knock Market은 개인 판매자 페이지를 중심으로 물건을 탐색하되, 그룹을 신뢰/노출 경계로 유지하는 중고마켓 서비스입니다.

- 핵심 가치: 개인 판매자의 취향/맥락, 신뢰 기반 거래, 예약 중심 플로우, 낮은 진입 장벽
- 핵심 흐름: 회원가입/로그인 -> 그룹 생성/가입 -> 상품 등록(거래 위치 선택) -> 개인 판매 페이지/그룹 피드 탐색 -> 예약/승인/완료 -> 알림
- 전환 방향: “폐쇄형 그룹 마켓”에서 “그룹 신뢰망 위의 개인형 중고마켓”으로 이동

## 2. 아키텍처 요약

- 멀티 모듈 Gradle 프로젝트
- `core:core-api`: Controller/Service/실행 애플리케이션
- `core:core-auth`: 세션 기반 인증
- `storage:db-core`: JPA Entity/Repository
- `storage:memory`: Redis/세션 저장소
- `infra:s3`: 이미지 업로드 인프라
- `tests:api-docs`: REST Docs 공통 테스트 모듈

## 3. 현재 구현 상태 (2026-04-14)

### 구현 완료

- 인증: 이메일/비밀번호 기반 로그인/로그아웃(세션 쿠키)
- 회원: 회원가입, 내 정보 조회/수정, 알림 설정 조회/수정, 차단/해제
- 그룹: 생성, 상세/목록 조회, 초대코드 생성, 초대코드 가입, 탈퇴
- 상품: 등록/조회/삭제(삭제 시 활성 예약 자동 취소), 그룹 피드, 판매자별 목록, 내 판매 목록
- 개인 판매 페이지: 공개 판매자 상품 조회 API와 프론트 판매자 페이지(`/seller/:memberId`) 추가
- 거래 위치: 상품 등록 시 거래 위치 이름/주소/위도/경도 저장, 상세 화면에서 Naver Map 또는 Naver Map 검색 링크로 노출
- 찜: 토글 및 내 찜 목록 조회(상품 `type/category/status/itemCreatedAt` 포함)
- 예약: 신청/승인/완료/취소, 내 예약 목록, 판매자용 예약 목록
- 알림: 생성, 목록 조회, 개별 읽음 처리, 전체 읽음 처리
- 후기/매너온도: 거래 완료 기반 후기 작성 및 매너온도 반영

### 미구현 또는 고도화 필요

- 소셜 로그인 Kakao 백엔드 연동
- SSE/실시간 알림 푸시
- 검색/필터 고도화(판매자 필터는 프론트 그룹 피드에 우선 반영)
- Naver Map 주소 검색/좌표 선택 자동화
- 운영 환경 인프라(배포/관측/경보) 강화
